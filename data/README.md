# Data Instructions

This repository does not redistribute the raw StatsBomb event dataset.

Obtain the original data from:
https://github.com/statsbomb/open-data

For this project, the relevant files are:

- La Liga 2020/2021 match metadata
- Match event JSON files
- Lineup JSON files where available

The original data source requests that any published research or analysis
credits StatsBomb and uses its official logo.

The analysis notebook downloads or processes the data locally.
Raw event JSON and combined raw event CSV files are deliberately excluded
from this repository.

Check the source repository and its current terms before reusing the data.
